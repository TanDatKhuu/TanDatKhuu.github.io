# Tan-Dat Khuu — Personal Academic Homepage (v3)

A lightweight, responsive academic website hosted on GitHub Pages, using a Navy & Teal theme.

## Update the live website

Repository: `TanDatKhuu/TanDatKhuu.github.io`

1. Extract `Tan_Dat_Khuu_Website_v3.zip` on your computer.
2. Open your GitHub repository and upload **the contents of the extracted folder**, not the enclosing folder.
3. Confirm that `index.html` is at the **repository root** and the following asset paths exist:
   - `assets/favicon.ico` (**new** — user's KTD logo)
   - `assets/favicon-32.png` (**new**)
   - `assets/apple-touch-icon.png` (**new**)
   - `assets/tan_dat_khuu_portrait.jpg`
   - `assets/Tan_Dat_Khuu_Academic_CV.pdf`
4. Commit changes to `main`. GitHub Pages updates automatically. Use Ctrl+F5 if browser favicon is still cached.

To avoid a repeated filename, you can edit `index.html` in GitHub or upload it and confirm GitHub shows it as a replacement to the old root file.

## How to update your own content

Open `index.html` and edit sections marked `id="research"`, `id="publications"`, `id="resources"` or individual `resources-...` pages. The software showcase is inside research project 04. Add screenshots only after you choose what to share publicly; do not put private source code or secrets into this public GitHub Pages repository. Any HTML/CSS/JS deployed to GitHub Pages is visible to website visitors.
