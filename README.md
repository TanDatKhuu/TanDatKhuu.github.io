# Tan-Dat Khuu | Academic Homepage

A lightweight personal academic website created from the attached academic CV and portrait.

## How to preview
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Use the top navigation to browse Home, Publications, Research, Talks & Workshops, Teaching, and Contact.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `your-username.github.io`.
2. Upload `index.html` and the entire `assets` directory to the repository root.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.
4. GitHub will provide the site's public URL after publishing.

## Editing your homepage
- Open `index.html` in an editor such as VS Code or Notepad.
- Update About me / Research / Publications / Teaching content directly in the HTML.
- Replace `assets/tan_dat_khuu_portrait.jpg` to change the circular portrait.
- Replace `assets/Tan_Dat_Khuu_Academic_CV.pdf` when your academic CV changes.
- All styling and navigation JavaScript are inside `index.html`; no packages or external frameworks are needed.
